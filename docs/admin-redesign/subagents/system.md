# Subagent report: система

## Общее

Системные пункты сайдбара: `Пользователи`, `Настройки`, `Telegram`. `Settings` и `Telegram` доступны только `ADMIN`. `Status Center` сейчас кнопка в header.

## Дашборд

### Сейчас

`src/admin/pages/Dashboard.tsx` грузит `/api/admin/dashboard-summary`, показывает версию и 4 KPI-карточки.

### Проблемы

- Это набор ссылок, а не рабочий дашборд.
- Нет приоритетов, ошибок, очередей и динамики.
- Версия проекта занимает отдельный блок, но не помогает оператору.

### Новая вкладка

`HQ Overview`: сводка операций, блок `требует внимания`, активные партии/заказы/очереди, короткие CTA.

### Подпункты mega-nav

- `Сводка`
- `Операции`
- `Риски`
- `Релиз`

## Пользователи

### Сейчас

`src/admin/pages/Users.tsx`: таблица пользователей, роли, баланс, Telegram-статус, создание пользователя, ручная Telegram-привязка.

### Проблемы

- Нет поиска/фильтрации по ролям.
- Нет карточки пользователя.
- Статус всегда `Активен`.
- Telegram-привязка требует ручного переноса `chat_id` и не связана с вкладкой Telegram.

### Новая вкладка

`Users & Access`: фильтры ролей, таблица, drawer пользователя, side panel создания и Telegram-привязки.

### Подпункты mega-nav

- `Аккаунты`
- `Роли`
- `Telegram ID`
- `Балансы`
- `Аудит`

## Настройки

### Сейчас

`src/admin/pages/Settings.tsx` фактически файловый менеджер `public/uploads`: метрики диска, breadcrumbs, сортировка, папки партий, фильтр локаций, создание папки, upload, drag/drop, удаление.

### Проблемы

- Название `Настройки` шире фактического содержимого.
- Удаление через `window.confirm`, без корзины/preview.
- Upload и файловая навигация перегружены в одной панели.

### Новая вкладка

`Storage / Files`: если оставить `Настройки`, разбить на системные настройки, хранилище и интеграции.

### Подпункты mega-nav

- `Диск`
- `Файлы`
- `Папки партий`
- `Загрузка`
- `Очистка`

## Telegram

### Сейчас

`src/admin/pages/TelegramBots.tsx`: боты, token validation, роли-получатели, manual recipients, low-stock threshold, recent chats, event groups, sticky save bar.

### Проблемы

- Слишком много разных задач на одном экране.
- Переключение ботов внутренними табами.
- Нет теста отправки.
- `token` выглядит как обычное поле.

### Новая вкладка

`Telegram Center`: список ботов слева, detail справа, события и получатели отдельными режимами, save bar оставить.

### Подпункты mega-nav

- `Боты`
- `Получатели`
- `События`
- `Чаты`
- `Тест`

## Status Center / HQ Desktop

### Сейчас

`src/admin/components/DesktopStatusCenter.tsx` — глобальная кнопка с health summary и drawer tabs `Обзор`, `Загрузки`, `Обновления`, `Диагностика`.

### Проблемы

- Критичная системная зона спрятана в drawer.
- Web/Desktop различия не отражены в навигации.
- Диагностика перегружена декоративными стилями и JSON dump.

### Новая вкладка

Самостоятельный route `/admin/status` или `/admin/hq-desktop`. Header-кнопку оставить как компактный индикатор.

### Подпункты mega-nav

- `Обзор`
- `Очереди`
- `Обновления`
- `Диагностика`
- `Логи`
