# Subagent report: продажи

## Общее

- Продажи в сайдбаре: `src/admin/components/Sidebar.tsx`.
- Роуты: `src/App.tsx`, `src/admin/components/AdminLayout.tsx`.
- API sales закрыт ACL.
- Статусы и переходы заказов находятся в `shared/domain/policy.ts`.

## Заказы

### Сейчас

Очередь заказов сайта, поиск, фильтры `ACTIVE/NEW/IN_PROGRESS/PACKED/DELIVERY/RETURNS/CLOSED`, карточка заказа, редактирование контактов/адреса/комментариев, трек СДЭК, синхронизация, резерв items, таймлайн.

### Проблемы

- Много действий в одной карточке.
- Фильтры выглядят как локальные чипы, хотя это основные рабочие очереди.
- `Скрыть` опасно рядом с рабочими действиями.
- Нет табличного режима массового контроля.
- Доставка и возвраты спрятаны внутри общей карточки.

### Новая вкладка

Операционный пульт заказов: очереди по статусам, таблица/список, справа drawer заказа. Действия показывать только по текущему этапу. Доставку и возвраты выделить в специализированные режимы.

### Подпункты mega-nav

- `Новые` — прием заказа.
- `В работе` — подтверждение/сбор.
- `Упакованы` — трек и отправка.
- `Доставка` — СДЭК и получение.
- `Возвраты` — причина и обратная логистика.
- `Закрытые` — read-only архив.

## Клиенты

### Сейчас

Список buyer-пользователей с заказами, поиск, автокарточка выбранного клиента, метрики заказов/доставок/возвратов/выручки, последние контакты, список заказов.

### Проблемы

- Нет сегментов клиентов.
- Карточка read-only без явной связи с заказом.
- Статусы заказов местами raw enum.
- Нет оценки ценности/риска клиента.

### Новая вкладка

CRM-реестр: таблица клиентов с контактами, заказами, выручкой, возвратами и последним заказом. Карточка клиента в drawer.

### Подпункты mega-nav

- `Все клиенты`
- `Повторные`
- `С возвратами`
- `Высокая выручка`
- `Карточка`

## Наличие в продаже

### Сейчас

Wide workspace: фильтры по поиску/локации/остатку/публикации/цене, сортировка, пагинация, таблица товаров, раскрытие product в item-группы `FREE/RESERVED/SOLD/OTHER`.

### Проблемы

- Перегруженная строка фильтров.
- Раскрытие item внутри широкой таблицы тяжелое.
- Нет отдельных exception queues.
- `На сайте/Скрыт` выглядит как переключатель, но не меняет состояние.

### Новая вкладка

Inventory console: плотная таблица, item detail в drawer/нижней панели, отдельные exception queues.

### Подпункты mega-nav

- `Все`
- `Свободные`
- `Резерв`
- `Нет/низкий остаток`
- `Сайт`
- `Items`

## История продаж

### Сейчас

Read-only список финальных `RECEIVED/RETURNED`, поиск, счетчики получено/возвращено/выручка.

### Проблемы

- Архив слишком упрощен.
- Нет периодов, сортировок, экспорта, деталей состава заказа.
- Возвраты и продажи смешаны одной карточной лентой.

### Новая вкладка

Аналитический журнал: таблица с периодом, статусом, клиентом, суммой, контактами, ответственным и ссылкой на заказ.

### Подпункты mega-nav

- `Все события`
- `Получено`
- `Возвраты`
- `Выручка`
- `Экспорт`
