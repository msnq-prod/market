# Subagent report: контент, планета, QR

## Товары и локации

### Сейчас

`src/admin/pages/Products.tsx` объединяет локации, товарные шаблоны, публикацию, партии, items, QR-переход, заказы на сбор. Загрузка: `/api/locations`, `/api/products`, `/api/categories`, `/api/users`.

### Проблемы

- Перегруженная вкладка.
- Разные сущности спрятаны в одном drill-down.
- `Редактировать локации` меняет режим всей сетки.
- Партии/items раскрываются глубоко внутри карточки шаблона.
- Item только read-only modal.
- QR-печать открывается отдельным окном без явного контекста.

### Новая вкладка

`Каталог HQ`: master-detail. Локации, шаблоны, партии и items не смешивать в одной карточке. Для массовых операций использовать таблицы.

### Подпункты mega-nav

- `Локации`
- `Товарные шаблоны`
- `Партии и Items`
- `Заказы на сбор`

## Планета

### Сейчас

`src/admin/pages/PlanetLabels.tsx` — fullscreen-редактор подписей локаций: список, поиск, desktop/mobile профиль, 3D Canvas, правый инспектор смещения и направления.

### Проблемы

- Название `Планета` шире фактической задачи.
- Нет пакетного сохранения.
- Конфликты видны, но сохранение разрешено.
- Desktop/mobile значения независимы, но это не очевидно.
- Список локаций отделен от CRUD локаций в `Products`.

### Новая вкладка

Визуальный редактор `Подписи планеты`: слева локации и фильтр конфликтов, центр 3D preview, справа свойства выбранной подписи.

### Подпункты mega-nav

- `Обзор планеты`
- `Подписи Desktop`
- `Подписи Mobile`
- `Конфликты`

## QR-печать

### Сейчас

`src/admin/pages/QrPrint.tsx` — PDF-конструктор. Берет `batchId/mode/ids` из URL, грузит товары, партии, QR-pack, пресеты, хранит layout/draft в localStorage. Слева источник данных и выбор items, центр A4 preview, справа настройки геометрии/полей/шрифтов. Экспорт через `html2canvas` + `jspdf`.

### Проблемы

- Слишком много настроек в одном длинном правом скролле.
- Пресеты находятся в панели источника, хотя относятся к layout.
- Выбор партии зависит от товара, нет глобального поиска batchId.
- Fullscreen-окно отделено от контекста приемки/каталога.
- Ручной выбор items плохо масштабируется.

### Новая вкладка

`QR-печать` как производственная станция: быстрый поиск партии/заказа, последние партии, A4 preview, панель layout-пресета. Для Electron: сохранить PDF, открыть папку, печать.

### Подпункты mega-nav

- `Партия`
- `Позиции`
- `Макет`
- `Пресеты`
- `Экспорт`

## Страница клона

### Сейчас

`src/admin/pages/CloneContent.tsx` редактирует тексты публичного цифрового паспорта. Поля заданы `FIELD_CONFIG`; preview по serial number через `/api/public/items/:serialNumber`; справа live-preview через `DigitalCloneView`.

### Проблемы

- Все тексты одним длинным списком.
- Нет группировки по блокам публичной страницы.
- Нет статуса влияния на реальные паспорта.
- Preview фиксирован узкой колонкой.
- Нет diff/истории/черновика публикации.

### Новая вкладка

`Паспорта Item` или `Контент паспорта`: слева дерево блоков страницы, центр форма выбранного блока, справа live-preview. Сохранение глобальное с предупреждением.

### Подпункты mega-nav

- `Hero`
- `Данные`
- `Media`
- `Подлинность`
- `Preview`
