# Редизайн HQ admin: mega-nav и рабочие вкладки

Дата: 2026-06-26.

Концепт-макет: `docs/admin-redesign/hq-mega-nav-concept.png`.

## Концепция

Новая админка строится вокруг двухстрочного верхнего mega-nav.

Первая строка: крупные блоки работы.

- `Обзор`
- `Продажи`
- `Товары`
- `Планета`
- `Система`

Вторая строка: подпункты активного блока. Подпункт не меняет только текст кнопок внутри одной универсальной страницы. Он открывает собственный рабочий интерфейс с отдельной компоновкой, фильтрами, главным действием и пустыми/ошибочными состояниями.

Большая выпадающая панель mega-menu допустима только как обзор блока: работа сейчас, справочники, инструменты. Основная ежедневная навигация находится во второй строке.

## Правила реализации

- URL и ACL текущих маршрутов сохраняются.
- `DesktopStatusCenter` остается доступен в верхней зоне.
- Fullscreen-инструменты (`Photo Tool`, `Video Tool`, `QR`, `PlanetLabels`) не встраиваются насильно в обычный layout.
- Для старых страниц допускается первый шаг: подключить новый top-nav и оставить текущий route.
- Следующий шаг для каждой вкладки: разнести сценарии на самостоятельные view-компоненты, а не на один generic workspace.
