# Вкладка: Наличие в продаже

## Сейчас

Файл: `src/admin/pages/SalesInventory.tsx`.

Wide workspace с фильтрами, сортировкой, пагинацией, таблицей товаров и раскрытием items по группам `FREE`, `RESERVED`, `SOLD`, `OTHER`.

## Проблемы UX/UI

- Строка фильтров перегружена.
- Детали item раскрываются внутри таблицы и ломают плотность.
- Не выделены exception queues: нет свободных, низкий остаток, резервы без движения.
- Публикация выглядит как управляемое состояние, хотя интерфейс read-only.

## Новая реализация

`Inventory Console`.

- плотная таблица товаров;
- item detail в правом drawer или нижней панели;
- отдельные очереди проблем наличия;
- режим `Items` для серийников, batch и clone-ссылок.

## Вторая строка mega-nav

- `Все`: полная таблица.
- `Свободные`: доступно к продаже.
- `Резерв`: привязано к заказам.
- `Нет/низкий остаток`: проблемы наличия.
- `Сайт`: опубликовано/скрыто.
- `Items`: серийники и паспорта.
