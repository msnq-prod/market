# Вкладка: Планета

## Сейчас

Файл: `src/admin/pages/PlanetLabels.tsx`.

Fullscreen-редактор подписей локаций: список локаций, поиск, desktop/mobile профиль, 3D preview и инспектор смещений.

## Проблемы UX/UI

- Название `Планета` шире фактической задачи.
- Нет пакетного сохранения.
- Конфликты видны, но сохранение разрешено.
- Desktop/mobile значения независимы, но это не очевидно.

## Новая реализация

`Редактор подписей планеты`.

- слева: локации и фильтр конфликтов;
- центр: 3D preview;
- справа: свойства подписи;
- состояния: изменено, конфликт, сохранено.

## Реализовано

- `/admin/planet-labels/workspace` — HQ shell-экран с очередью локаций, desktop/mobile состояниями, поиском и фильтром проверки.
- `/admin/planet-labels` — сохранен как fullscreen 3D-редактор для точной настройки offsets.
- Мегаменю ведет сначала в workspace, а запуск fullscreen вынесен отдельным действием.

## Вторая строка mega-nav

- `Обзор`: все локации и видимость.
- `Desktop`: desktop offset/direction.
- `Mobile`: mobile offset/direction.
- `Конфликты`: проблемные подписи.
