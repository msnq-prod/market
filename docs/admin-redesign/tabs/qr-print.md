# Вкладка: QR-печать

## Сейчас

Файл: `src/admin/pages/QrPrint.tsx`.

Fullscreen PDF-конструктор: источник данных из URL, выбор items, A4 preview, layout-настройки, пресеты и экспорт через `html2canvas` + `jspdf`.

## Проблемы UX/UI

- Слишком много настроек в одном правом скролле.
- Пресеты находятся рядом с источником, хотя относятся к макету.
- Нет глобального поиска batchId.
- Окно отделено от контекста приемки/каталога.

## Новая реализация

`QR Print Station`.

- быстрый поиск партии/заказа;
- последние партии;
- A4 preview;
- отдельная панель макета и пресетов;
- Electron-действия: сохранить PDF, открыть папку, печать.

## Реализовано

- `/admin/qr` — HQ shell-экран с поиском batch, выбором режима, последними партиями, пресетами и workflow-панелями.
- `/admin/qr/print` — сохранен как fullscreen PDF-конструктор и совместим с query `batchId`, `mode`, `ids`.
- Пункты mega-nav `QR` и `QR-печать` ведут в workspace с разным `context`, без `target=_blank`.

## Вторая строка mega-nav

- `Партия`: источник QR.
- `Позиции`: all/selected и порядок.
- `Макет`: размеры, поля, QR side, шрифты.
- `Пресеты`: CRUD шаблонов.
- `Экспорт`: PDF/save/print.
