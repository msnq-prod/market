# Вкладка: Клиенты

## Сейчас

Файл: `src/admin/pages/Clients.tsx`.

Страница показывает список клиентов, поиск, выбранного клиента, метрики заказов/доставок/возвратов/выручки, контакты и историю заказов.

## Проблемы UX/UI

- Нет сегментов клиентов.
- Заказы внутри клиента не ведут явно к рабочей карточке заказа.
- Статусы заказов частично отображаются как raw enum.
- Нет risk/value представления клиента.

## Новая реализация

`CRM-реестр`.

- основа: таблица клиентов;
- колонки: контакты, последний заказ, выручка, возвраты, риск;
- справа: профиль клиента с историей и переходами к заказам;
- отдельные сегменты для повторных, рисковых и ценных клиентов.

## Вторая строка mega-nav

- `Все клиенты`: поиск и таблица.
- `Повторные`: несколько заказов.
- `С возвратами`: риск-лист.
- `Высокая выручка`: сортировка по revenue.
- `Карточка`: профиль выбранного клиента.

## Реализовано

Файл: `src/admin/pages/Clients.tsx`.

- добавлены сегменты `Все`, `Повторные`, `С возвратами`, `Высокая выручка`;
- список и summary теперь считают выбранный сегмент;
- выбранная карточка клиента синхронизируется с сегментом.
