# Вкладка: Распределение

## Сейчас

Файл: `src/admin/pages/Allocation.tsx`.

Страница берет items со статусом `STOCK_HQ`, дает массовый выбор карточек и распределяет выбранное в канал `MARKETPLACE`.

## Проблемы UX/UI

- Выглядит как MVP-заглушка.
- Нет группировки по локации, товару, партии.
- Нет preview последствий.
- Успех показывается через `alert()`.

## Новая реализация

`Distribution Desk`.

- слева: фильтры склада;
- центр: таблица item;
- справа: панель назначения;
- summary перед подтверждением;
- режимы каналов расширяются только после подтверждения бизнес-логики.

## Вторая строка mega-nav

- `HQ stock`: доступные `STOCK_HQ`.
- `Онлайн`: назначение на marketplace.
- `Консигнация`: отдельный сценарий с получателем.
- `История движений`: журнал распределений.

## Реализовано

Файл: `src/admin/pages/Allocation.tsx`.

- добавлен рабочий header `Distribution desk`;
- добавлены метрики HQ stock / видимо / выбрано;
- поиск оформлен как часть рабочего стола;
- `alert()` заменен на inline notice;
- добавлен preview выбранных видимых позиций перед подтверждением.
