# Вкладка: Страница клона

## Сейчас

Файл: `src/admin/pages/CloneContent.tsx`.

Редактор текстов публичного цифрового паспорта. Поля заданы в `FIELD_CONFIG`, справа live-preview через `DigitalCloneView`, preview можно привязать к serial number.

## Проблемы UX/UI

- Все тексты одним длинным списком.
- Нет группировки по блокам публичной страницы.
- Нет статуса влияния на реальные паспорта.
- Preview узкий и не поддерживает полноценный review.

## Новая реализация

`Контент паспорта Item`.

- слева: дерево блоков страницы;
- центр: форма выбранного блока;
- справа: live-preview демо или реального item;
- save явно показывает, что изменит все публичные паспорта.

## Вторая строка mega-nav

- `Hero`: бейдж и описание.
- `Данные`: дата, время, координаты, serial.
- `Media`: фото/видео и empty state.
- `Подлинность`: блок доверия.
- `Preview`: демо item или serial number.

## Реализовано

Файл: `src/admin/pages/CloneContent.tsx`.

- форма сгруппирована по блокам `Hero`, `Данные`, `Media`, `Подлинность`;
- header явно показывает, что изменения влияют на все публичные паспорта Item;
- live-preview и загрузка preview по serial number сохранены.
