# Scope

- Цель: зависание фонового сохранения 150 фото в Photo Tool.
- Границы: UI `PhotoTool`, desktop media workflow, Photo Tool v2 upload API.
- Не входит: изменение бизнес-статусов партий/items, ручные DDL-правки.
- Ожидаемое поведение: после передачи в фон фото конвертируются/загружаются, прогресс растет или показывается терминальная ошибка.

## Commands

- `rg` по Photo Tool/workflow/upload.
