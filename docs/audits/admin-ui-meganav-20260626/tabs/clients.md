# Вкладка: Клиенты

## Что есть сейчас

Route: `/admin/clients`.

Файл: `src/admin/pages/Clients.tsx`.

Страница уже работает как простая CRM-карточка:

- верхний заголовок, описание и `Обновить`;
- summary: клиенты, доставки, возвраты;
- сегменты: все клиенты, повторные, с возвратами, высокая выручка;
- левый список клиентов с поиском;
- выбранный клиент открывается справа;
- карточка клиента показывает имя, username, email, выручку, метрики, телефон, адрес и список заказов.

## UX/UI проблемы

- Вкладка уже похожа на two-pane CRM, но не доведена до трехзонной схемы: контактные данные, метрики и история смешаны в одном правом блоке.
- Сегменты вынесены отдельной full-width панелью и занимают рабочую высоту, хотя это навигация/фильтр left rail.
- Summary-карточки повторяют часть данных, но не помогают выбрать клиента или действие.
- Заказы клиента показаны как локальные карточки без явного перехода в заказ, без timeline и без контекста возвратов.
- Статусы заказов отображаются raw enum, без единого sales-language.
- Нет быстрых действий: открыть заказы клиента, скопировать контакт, перейти к истории продаж по клиенту.
- Клиенты визуально могут смешиваться с системной вкладкой `Пользователи`; нужен явный sales CRM-контекст.

## Как должно выглядеть

- **Left rail:** поиск, сегменты, dense список клиентов, last order, revenue/returns сигнал, selected state.
- **Center workbench:** выбранный клиент как рабочая область: timeline заказов, статусы, суммы, возвраты, переходы в read-only/working order.
- **Right inspector:** контакты, адрес, lifetime stats, сегмент, риск возвратов, быстрые действия.

Цель: `Клиенты` должны читаться как sales CRM, а не как список пользователей.

## Ожидаемые правки

- Перенести сегменты и поиск в left rail.
- Убрать верхние summary-карточки или заменить их компактными счетчиками в rail/inspector.
- Оставить в center только историю и рабочий контекст выбранного клиента.
- Вынести контакты, lifetime stats и quick actions в sticky right inspector.
- Нормализовать статусы заказов через человекочитаемые labels.
- Добавить переходы: заказ, история продаж по клиенту, копирование контакта.
- Добавить пустое состояние для отсутствия выбранного клиента и состояния ошибки detail-загрузки без сброса всего списка.

## Быстрые действия

- Открыть заказы клиента.
- Создать/привязать заказ.
- Скопировать контакт.
- Отфильтровать историю по клиенту.
