# Вкладка: История продаж

## Что есть сейчас

Route: `/admin/sales-history`.

Файл: `src/admin/pages/SalesHistory.tsx`.

Страница работает как простой read-only архив:

- верхний заголовок, описание и `Обновить`;
- summary: получено, возвращено, выручка;
- фильтр статуса: все события, получено, возвраты;
- поиск по ID, логину и контактам;
- список карточек завершенных заказов `RECEIVED` и `RETURNED`;
- карточка показывает короткий ID заказа, дату, статус, сумму, покупателя и контакт.

## UX/UI проблемы

- Архив слишком похож на ленту карточек, хотя это read-only/reporting экран.
- Нет периода, сортировки, группировки и экспорта.
- Summary стоит над задачей и занимает высоту, но не закреплен как итог текущей выборки в inspector.
- Фильтр статуса и поиск находятся внутри общего блока, а не в отдельном filter rail.
- Нет selected order/detail: нельзя быстро проверить состав, клиента, возврат и переходы.
- Продажи и возвраты визуально смешаны; возвраты не показывают причину/потерю.
- Нет связки с `Клиенты`: клиент в карточке не является точкой перехода.

## Как должно выглядеть

- **Left rail:** период, статус, клиент, канал/источник, поиск, saved filters.
- **Center workbench:** read-only таблица завершенных событий: дата, заказ, клиент, статус, сумма, возврат, контакт.
- **Right inspector:** итог выборки, экспорт, выбранный заказ, состав заказа, переход к клиенту/заказу.

Цель: `История продаж` должна быть журналом и отчетом, не рабочей очередью.

## Ожидаемые правки

- Перевести список карточек в dense read-only table.
- Добавить selected order и detail в right inspector.
- Перенести поиск и фильтры в left rail.
- Добавить фильтр периода и сортировку по дате/сумме.
- Перенести агрегаты `Получено`, `Возвращено`, `Выручка` в right inspector как итог текущей выборки.
- Добавить export action в inspector.
- Добавить переходы к клиенту и заказу.
- Для возвратов показывать отдельный financial impact: сумма возврата/потеря.

## Быстрые действия

- Экспорт текущего фильтра.
- Открыть заказ read-only.
- Перейти к клиенту.
