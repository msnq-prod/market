# Вкладка: Паспорта

## Что есть сейчас

Route: `/admin/clone-content`.

Назначение: настройка текстового контента публичного цифрового паспорта Item.

Текущий экран:

- Загружает/сохраняет общий контент паспорта через `/api/content/clone-page`.
- Редактирует группы текстов: `Hero`, `Данные`, `Media`, `Подлинность`.
- Имеет поле загрузки preview по `serial_number`.
- Показывает live-preview через `DigitalCloneView`.
- Preview расположен справа от формы на широком экране.
- Нет списка Item/passport-объектов и нет выбора паспорта как рабочей сущности.

## UX/UI проблемы

- UI выглядит как форма глобального контента, но вкладка называется как операционная работа с паспортами.
- Связь паспорта с `Item.serial_number`, а не Product, не закреплена как главный контекст.
- Нет очереди Item с состояниями паспорта.
- Нет явной проверки условий публикации паспорта: legacy token, batch status, rejected item, скрытые Batch/Product/Location.
- Preview есть, но правый контекст не содержит QR, link actions и blockers.
- Статусы сохранения/preview показаны текстом, без устойчивой зоны состояния.
- Формы сгруппированы правильно, но не встроены в трехзонный workspace.

## Как должно выглядеть

- **Left rail:** очередь Item passports, поиск по `serial_number`, фильтры `Все`, `Доступен`, `Заблокирован`, `Без QR`, `Rejected`.
- **Center workbench:** редактор контента публичного паспорта: секции `Hero`, `Данные`, `Media`, `Подлинность`, dirty-state, save/reset.
- **Right inspector:** public preview, clone URL, QR, быстрые действия, blockers доступности.

## Ожидаемые правки

- Переименовать рабочий контекст в UI так, чтобы было ясно: редактируется общий контент паспорта, а preview выбирается по Item.
- Добавить left rail с Item/passport queue или явно отделить текущий экран как `Контент паспорта`, если очередь не входит в scope.
- Вынести preview, clone URL, QR и blockers в правый inspector.
- Показывать eligibility-чек паспорта отдельным блоком:
  - `serial_number` не legacy token;
  - batch в `RECEIVED` или `FINISHED`;
  - item не `REJECTED`;
  - связанные Batch/Product/Location не скрыты.
- Сохранить текущие группы текстовых полей, но разместить их в center workbench.

## Быстрые действия

- Открыть публичный паспорт.
- Скопировать clone URL.
- Проверить QR.
- Перейти к batch/item.
