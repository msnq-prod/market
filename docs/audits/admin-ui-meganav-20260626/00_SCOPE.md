# Scope

Дата: 2026-06-26.

## Цель

Полный UX/UI-аудит обновленной HQ-админки после внедрения mega-nav и route-level вкладок.

Фокус: рабочие вкладки админки, second-row navigation, первый экран, реальные действия, соответствие UI бизнес-процессам.

## Приоритеты ремонта

1. Убрать лишний page-title band из app shell.
2. Вернуть первый экран к рабочим действиям, а не декоративным summary-блокам.
3. Сократить/сгруппировать вкладки без явной функции.
4. Исправить приемку: выбранная партия и действие должны быть видны без прокрутки.
5. Зафиксировать отдельный документ по каждой вкладке.
6. Убрать растянутые full-width полосы там, где страница является queue/detail workspace.
