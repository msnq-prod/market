# UI Function Map

| Сценарий | Текущая роль | Фактическое действие |
|---|---|---|
| Очередь | Приоритизация работы | Фильтрует статический массив, открывает локальный mock |
| Локации | CRUD локаций | Меняет локальный state, показывает ложное сохранение |
| Шаблоны | CRUD шаблонов | Меняет локальный state, показывает ложное сохранение |
| Заказы на партии | Создание и контроль | Меняет локальный state, показывает ложное сохранение |
| Приемка | Прием партии | Переключает локальный флаг `received` |
| Фото | Подготовка item-фото | Имитирует Photo Tool без API и desktop runtime |
| Видео | Монтаж item-видео | Имитирует Video Tool без IPC, рендера и upload |
| QR и паспорта | Идентификация и печать | Имитирует номера и печать без QR Print |
| На склад | Проверка и финализация | Имитирует проверку таймером и локальным статусом |
| Склад | Остатки и списание | Меняет локальный словарь состояний |

Реальные рабочие поверхности уже существуют:

- `/admin/photo-tool/:batchId`;
- `/admin/video-tool/:batchId`;
- `/admin/qr/print`;
- `/admin/acceptance`;
- `/admin/warehouse`.
