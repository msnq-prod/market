# Negative Paths

Не обработаны:

- reload после локального success;
- browser back/forward для `productsView`;
- удаленная или неизвестная партия;
- API failure и истекшая авторизация;
- конфликт параллельного редактирования;
- desktop runtime недоступен;
- частичный render/upload media;
- повторный клик;
- пустая очередь;
- неверное количество при приемке;
- отмена приемки и отмена финализации;
- backend-блокеры финализации;
- права на отдельные операции.
