# UI Consistency Matrix

| Область | Проблема |
|---|---|
| Фото | Generic upload mock вместо существующего Photo Tool |
| Видео | Тот же шаблон, что у фото, хотя процесс включает timeline, render и upload |
| QR | Локальная кнопка печати вместо реального QR Print |
| Локации | В `Товары` попали переводы и позиционирование подписи планеты |
| Шаблоны | В `Товары` попали публикация, маркетплейсы и переводы |
| Экраны | Локации, шаблоны, заказы, приемка и media повторяют один list/detail шаблон |
| Термины | `Сохранено`, `Партия принята`, `На складе` показываются без изменения source of truth |
| Навигация | Меню открывается автоматически при загрузке и перекрывает рабочую область |
