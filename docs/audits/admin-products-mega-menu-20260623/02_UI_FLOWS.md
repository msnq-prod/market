# UI Flows

## Заявленный поток

`очередь -> конкретная задача -> рабочий интерфейс -> сохраненный результат`

## Фактический поток

`очередь со статикой -> декоративная копия рабочего интерфейса -> локальный success -> потеря результата после reload`

## Ошибка модели

Меню визуально выстраивает линейную цепочку:

`приемка -> фото -> видео -> QR -> склад`

Реальная модель после приемки параллельная:

- Photo Tool независимо закрывает покрытие фото;
- Video Tool независимо закрывает покрытие видео;
- QR доступен независимо от media;
- финализация проверяет фактическое состояние backend.

Фото, видео и QR могут оставаться пунктами меню как очереди задач, но не должны дублировать сами инструменты.
