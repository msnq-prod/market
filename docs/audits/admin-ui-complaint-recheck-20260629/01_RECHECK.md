# Recheck

## Общая оценка

Первый проход исправил товарные рабочие места, но часть админки все еще сохраняла старый паттерн: верхний заголовок, отдельная полоса метрик, отдельная полоса фильтров, затем рабочая зона.

## Подтвержденные проблемы

| Зона | Проблема | Решение |
|---|---|---|
| Обзор | Большой внутренний header поверх общего меню | Перевести в левый rail + right inspector |
| Клиенты | CRM почти two-pane, но фильтры и summary вынесены отдельными полосами | Сегменты/поиск в rail, контакты/метрики в inspector |
| История продаж | Header + KPI + фильтры + список в одну колонку | Фильтры в rail, события в center, итоги справа |
| Наличие | Очень широкая таблица, все фильтры одной верхней полосой | Фильтры и сортировку вынести в rail, summary/actions справа |
| Пользователи | Большой блок `Users & access`, потом фильтры, потом таблица | Роли/поиск слева, таблица в center, доступы/действия справа |
| Настройки | Header и дисковая панель занимают верх перед файловой работой | Навигация и storage summary слева/справа |
| Telegram | Header + внутренние вкладки + bot tabs создают лишний слой навигации | Боты слева, текущий режим в center, сохранение/actions справа |
| Планета labels | KPI-полоса сверху | Метрики и фильтры в rail/inspector |
| Clone content | Header сверху и preview рядом, но actions не закреплены | Секции слева, редактор в center, preview/actions справа |
