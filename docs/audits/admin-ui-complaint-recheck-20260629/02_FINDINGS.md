# Findings

### P1-01: Старые page headers остались на части вкладок

- **Факт:** `Clients`, `SalesHistory`, `Users`, `Settings`, `Telegram`, `CloneContent`, `PlanetLabelsWorkspace` рендерят собственный крупный header.
- **Эффект:** повторяется проблема из скриншота: рабочая задача уходит ниже.
- **Правка:** убрать внутренние hero/header-полосы, смысл перенести в rail/inspector.
- **Статус:** in progress.

### P1-02: Продажные вкладки не полностью самостоятельны

- **Факт:** `Clients`, `Inventory`, `SalesHistory` используют похожую структуру “заголовок + KPI + фильтры + список”.
- **Эффект:** вкладки выглядят как варианты одной страницы.
- **Правка:** для каждой вкладки сделать собственный расклад: CRM, складская таблица, журнал событий.
- **Статус:** in progress.

### P2-01: Служебный English/technical copy

- **Факт:** встречаются `Users & access`, `buyer-логин`, `serial number`, `items`, `batch`, `Low-stock`, `Telegram center`.
- **Эффект:** интерфейс выглядит прототипом.
- **Правка:** заменить видимый текст на русский рабочий язык, оставив технические значения только там, где это идентификатор.
- **Статус:** in progress.

### P2-02: Навигационные режимы дублируют локальные вкладки

- **Факт:** Telegram и Settings имеют и mega-nav entry, и собственные вкладки/режимы.
- **Эффект:** возникает ощущение лишних вкладок без функции.
- **Правка:** оставлять локальные режимы только как рабочие переключатели внутри самостоятельной вкладки, а не как визуальный второй глобальный сайдбар.
- **Статус:** pending.
